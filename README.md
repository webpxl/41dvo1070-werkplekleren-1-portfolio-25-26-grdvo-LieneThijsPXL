Portfolio Website – Werkplekleren 1
Dit project is mijn persoonlijke portfolio voor WPL1 binnen de opleiding Digitale Vormgeving. 
De website is volledig opgebouwd met HTML, CSS en JavaScript, zonder externe frameworks.


1  de site bevat:
- Een korte voorstelling
- Mijn motivatie en interesses
- Schoolprojecten en persoonlijke projecten
- Een aparte pagina met mijn Situering binnen Profiel DVO en Eindreflectie
- Een privacy‑richtlijnen pagina
- Responsieve lay‑out voor desktop, tablet en smartphone


2   Technische informatie
Talen: HTML, CSS, JavaScript
Versiebeheer: GitHub (min. 5 commits)
Hosting: GitHub Pages / Netlify
Structuur: Header – Main – Footer met duidelijke sections & articles
